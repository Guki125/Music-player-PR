# Neon Vibe Player 🎵

Навчальний веб-застосунок для пошуку та прослуховування музики, реалізований у рамках практики.

## 🚀 Функціонал
- **Пошук музики** через iTunes Search API.
- **3D Карусель** обкладинок (CSS Transform).
- **Аудіо-плеєр** з візуалізацією прогресу та перемотуванням.
- **Збереження історії** останнього пошуку (LocalStorage).
- **Адаптивний дизайн** (Neon Glassmorphism Style).

## 🛠 Технології
- HTML5 / SCSS
- JavaScript (ES6+, Async/Await)
- Vite (збирач проєкту)
- Axios (HTTP-запити)
- Bootstrap 5 (Модальні вікна, іконки)
